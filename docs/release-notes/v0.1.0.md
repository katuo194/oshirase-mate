おしらせメイトの最初のリリースです。

デスクトップに住むマスコットが、Google カレンダーの予定・Google ToDo リスト（Tasks）の期限・Gmail の重要なメールを、アニメーション・効果音・読み上げで知らせてくれる Windows アプリです。

## できること

- 予定のリマインダーの時刻、TODO の期限の日、重要なメールが届いたときに、マスコットが吹き出しで知らせます（重要でないメールは未読の件数をバッジで表示）
- [VOICEVOX](https://voicevox.hiroshiba.jp/) を起動しておくと、お知らせを声で読み上げます
- 最初から「メイト」「シアン」「シトロン」の3体が入っています。シアンとシトロンは、VOICEVOX が無くても録音してある声で話します
- [EmoteLab](https://emotelab.app/) で作ったキャラクターの取り込み、キャラクターごとの声・性格・セリフの設定
- Gemini API キーを設定すると、マスコットとのチャットと、キャラクターに合わせたセリフの案づくりが使えます

## ダウンロード

下の **Assets** から `oshirase-mate-shared-0.1.0-win-x64.zip` をダウンロードし、展開して `おしらせメイト.exe` を起動します。インストーラーはありません。

はじめての設定（Google との連携・VOICEVOX・Gemini API キー）は、添付の `setup-guide.html`（zip の中の `セットアップ手順書.html` と同じもの）と [README](https://github.com/katuo194/oshirase-mate#readme) を見てください。

## 動作環境・注意

- Windows 11（64ビット）
- Google との連携には、ご自分の Google アカウントで「連携用のクライアント」を作る必要があります（最初の1回だけ・15分ほど。手順書に沿って進められます）
- コード署名をしていないため、初回の起動時に「Windows によって PC が保護されました」と表示されることがあります（「詳細情報」→「実行」）。スマート アプリ コントロールが有効な PC では実行できません
