Google 連携の準備

自分の Google アカウントで連携用のクライアントを作ります（最初の1回だけ）。ボタンで Google Cloud のページが開きます。

  1. 1 プロジェクトを作り、API を有効にする

    プロジェクトを作成し、3 つの API を有効にします。

  2. 2 同意画面を設定して公開する

    でアプリ名とメールを入れて作成（対象は「外部」）。 で「アプリを公開」→ 本番環境に（テストのままだと 7 日で切れます）。

  3. 3 クライアントを作り、JSON をダウンロードする

    種類は「デスクトップ アプリ」。作成直後の画面で「JSON をダウンロード」（この画面でしか取得できません）。

  4. 4 ダウンロードした JSON を読み込む
    ここに client_secret_〜.json をドラッグ＆ドロップ

    確認中…

  5. 5 連携する

    「確認されていません」→「詳細」→「移動」。権限はすべて許可します。
