クライアント：確認中…

A. クライアントを受け取った人

  1. 1 受け取った Client ID と Client Secret を貼り付ける

    JSON ファイル（client_secret_〜.json）で受け取ったときは で読み込みます。

  2. 2 連携する

    ブラウザで Google アカウントを選び、「このアプリは Google で確認されていません」と出たら「詳細」→「おしらせメイト（安全ではないページ）に移動」。 権限のチェックはすべて入れて「続行」します。

B. 自分でクライアントを作る（30 分ほど）

自分の Google アカウントで Google Cloud のプロジェクトとクライアントを作ります。ボタンで Google Cloud のページが開きます。 この方法では連携が 7 日で切れます（切れる前にマスコットがお知らせするので、設定タブの「連携し直す」を押します）。

  1. 1-a プロジェクトを作る

    プロジェクト名（例：oshirase-mate）を入れて「作成」。「ようこそ」の画面になったら、次の手順へ進みます。

  2. 1-b 3 つの API を有効にする

    上に 1-a で作ったプロジェクト名が出ていることを確かめ、「次へ」→「有効にする」。

  3. 2 Google Auth Platform を設定する

    「開始」を押し、アプリ情報（アプリ名と自分のメール）→ 対象は「外部」→ 連絡先情報（自分のメール）→ 終了（ポリシーに同意して「続行」）→「作成」。 続けて の「テストユーザー」で「Add users」を押し、自分のメールアドレスを入れて「保存」。

  4. 3 クライアントを作り、JSON をダウンロードする

    種類は「デスクトップ アプリ」。作成直後の画面で「JSON をダウンロード」（この画面でしか取得できません）。

  5. 4 ダウンロードした JSON を読み込む
    ここに client_secret_〜.json をドラッグ＆ドロップ
  6. 5 連携する

    「確認されていません」→「詳細」→「（安全ではないページ）に移動」。権限はすべて許可します。

選ぶとすぐにマスコットに反映されます。
