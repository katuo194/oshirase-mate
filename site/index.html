おしらせメイト

デスクトップに住むマスコットが、Google カレンダーの予定・Google ToDo リストの期限・Gmail の重要なメールを、アニメーション・効果音・読み上げで知らせてくれる Windows アプリです。

ダウンロード セットアップ手順書

できること

  • 予定・TODO・重要メールのお知らせ予定のリマインダーの時刻、TODO の期限の日（設定した時刻）、重要なメールが届いたときに、マスコットが吹き出しで知らせます。重要でないメールは、未読の件数だけを小さなバッジで表示します。
  • 読み上げVOICEVOX を起動しておくと、お知らせを声で読み上げます。キャラクターごとに声を選べます。
  • アイドルトークしばらく操作がないと、マスコットがひとりごとを話します（深夜は話しません）。
  • チャットGemini API キーを設定すると、マスコットと会話できます（1 回の会話は 10 往復まで）。
  • キャラクター最初から 3 体が入っています。EmoteLab で作ったキャラクターを取り込むこともできます。
  • 見落としにくいWindows 標準の通知は使わず、マスコット自身が知らせます。

Google のデータを使う理由

おしらせメイトは、お知らせを出すために、次の 3 つを読み取り専用の権限で読み取ります。予定・タスク・メールを変更・削除・送信することはありません。

  • Google カレンダー：今後 24 時間の予定のタイトル・開始時刻・リマインダー（リマインダーの時刻に知らせるため）
  • Google ToDo リスト：未完了のタスクのタイトル・期限の日付（期限の日に知らせるため）
  • Gmail：未読のメールの件名・差出人・日時と、重要かどうか（重要なメールを知らせ、ほかの未読の件数を出すため）。本文は使いません。

読み取ったデータは、すべてお使いの PC の中で処理します。開発者のサーバーはなく、開発者にデータが届くことはありません。詳しくはプライバシーポリシーをご覧ください。

動作環境

  • Windows 11（64 ビット）
  • Google アカウント
  • 任意：VOICEVOX（読み上げを使う場合）
  • 任意：Gemini API キー（チャットを使う場合）

はじめかた

  1. Releases から最新の zip をダウンロードして展開し、おしらせメイト.exe を起動します（インストーラーはありません）。
  2. マスコットを右クリック →「設定」の「Google 連携」タブで、Google と連携します。

くわしい手順と困ったときの対処は、セットアップ手順書にまとめています。不具合やご質問は GitHub の Issues へどうぞ。
