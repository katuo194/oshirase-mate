プライバシーポリシー

制定日・最終更新日：2026年11月1日

おしらせメイト（以下「本アプリ」）は、katuo194（以下「開発者」）が個人で開発・配布している Windows 用のデスクトップアプリです。このページでは、本アプリが扱う情報と、その取り扱いについて説明します。

要点

  • Google のデータ（予定・タスク・メール）は読み取りだけで、すべてお使いの PC の中で処理します。
  • 開発者のサーバーはありません。開発者にデータが届くことはありません。
  • 広告、アクセス解析、利用状況の送信はしません。
  • Google のデータを AI（Gemini）に送ったり、AI の学習に使ったりしません。

1. 本アプリが読み取る Google のデータ

Google アカウントと連携すると、次のデータを読み取り専用の権限（スコープ）で読み取ります。予定・タスク・メールを変更・削除・送信することはありません。

サービス（スコープ）使うデータ使い道
Google カレンダー
calendar.readonly		 メインのカレンダーの、今後 24 時間の予定のタイトル・開始時刻・リマインダーの設定 リマインダーの時刻に、予定をお知らせする
Google ToDo リスト
tasks.readonly		 未完了のタスクのタイトル・期限の日付 期限の日の設定した時刻に、タスクをお知らせする
Gmail
gmail.readonly		 未読のメールの件名・差出人・日時と、Gmail が付けた「重要」の印 重要なメールをお知らせし、ほかの未読の件数をバッジに出す

メールの本文・添付ファイルは使いません（表示・保存・送信をしません）。Google アカウントのメールアドレスやプロフィールは読み取りません。

2. データの使い道

読み取ったデータは、お使いの PC の画面にお知らせを出し、読み上げるためだけに使います。広告、販売、利用者の分析、AI の学習には使いません。

3. PC に保存するもの

本アプリは、次のものをお使いの PC の %APPDATA%\おしらせメイト に保存します。開発者が見ることはできません。

  • Google との連携情報（リフレッシュトークン）・読み込んだクライアント（Client ID と Client Secret）・Gemini API キー：Windows の機能で暗号化して保存します。ログには記録しません。
  • お知らせ済みの記録：同じお知らせを二度出さないための ID で、7 日で消します。
  • ログ：エラーや状態の変化と、表示したお知らせの種類・タイトル（予定・タスクのタイトル、メールの件名と差出人の名前）・時刻を記録します。14 日分だけ残し、古いものは自動で消します。メールの本文、チャットの内容、トークン・Client Secret・API キーは記録しません。
  • 読み上げの音声：VOICEVOX で作った音声を一時的に保存し、読み上げが終わったら消します。
  • 設定と、作成・取り込んだキャラクター（キャラクター設定・セリフを含む）

予定・タスク・メールの一覧は保存せず、アプリを終了すると消えます。

4. 外部への送信

  • Google：連携と、予定・タスク・メールの読み取りのために、お使いの PC から Google のサーバーへ直接通信します。インターネットにつながっているかの確認のために、Google のサーバー（www.google.com）にも問い合わせます（データは送りません）。
  • Gemini（Google）：チャットで話しかけたときと、キャラクターの編集画面で「Gemini でセリフを作る」を押したときだけ、お使いの Gemini API キーで、入力した文章・キャラクター名・キャラクター設定を送ります。予定・タスク・メールの内容は送りません。送った内容の Google での扱いは、Gemini API の利用規約に従います（無料で使う場合、Google がサービスの改善に使うことがあります）。
  • VOICEVOX：読み上げのために、お知らせの文（タイトルや件名を含む）を、お使いの PC で動いている VOICEVOX へ送ります。PC の外には出ません。
  • 開発者：何も送りません。不具合の報告で、ログなどを GitHub の Issues に載せるかどうかは、利用者が決めることができます。

5. Google API サービスのユーザーデータに関するポリシーへの準拠

本アプリが Google API から受け取った情報の使用と、他のアプリへの転送は、限定使用の要件を含む Google API サービスのユーザーデータに関するポリシーに従います。

Oshirase Mate's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

あわせて、次のことを守ります。

  • Google のデータは、上に書いたお知らせの機能のためだけに使います。
  • Google のデータを、第三者に渡したり、販売したりしません。
  • Google のデータを人が読むことはありません（開発者はデータを受け取らないため、読むことができません）。
  • Google のデータを、AI・機械学習のモデルの作成や改善に使いません。

6. 連携の解除とデータの削除

  • 連携の解除：設定画面の「連携解除」を押すと、Google 側の許可を取り消し、PC に保存した連携情報を削除します。Google アカウントのサードパーティ製のアプリとサービスのページからも取り消せます。
  • データの削除：アプリを終了してから %APPDATA%\おしらせメイト フォルダを削除すると、本アプリが保存したものはすべて消えます。Gemini API キーだけを消したいときは、設定画面の「チャット（Gemini）」欄で削除できます。

開発者はデータを持っていないため、開発者への削除のご依頼は必要ありません。

7. このポリシーの変更

本アプリの機能が変わったときなどに、このポリシーを変更することがあります。変更したときは、このページで内容と最終更新日を書き換えます。

8. お問い合わせ

このポリシーや本アプリについてのお問い合わせは、GitHub の Issues へお寄せください。Issues は誰でも見られるため、個人情報は書かないでください。
